# discrete_math

In this project, I implemented:
- Authentication via Firebase
- All graph data is stored in Firestore
- On the Editor Screen, I implemented moving vertices, adding and changing their information
- BFS and DFS work with animation
- Detour finds the path instantly
- In the detailed information, you can change the main vertex, or change to the path type
- implemented a dark theme
