# discrete_math
The main goal is to implement graph drawing and perform various operations on them:
-BFS
-DFS
-Edit graph
-Information about the graph, whether it is Eulerian or some other information
-Traversal from one vertex to another
Thanks to this project I am preparing for the exam in discrete mathematics,
Also implemented here:
-authentication
-settings
-file save on online database
